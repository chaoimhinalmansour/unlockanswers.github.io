# UNLOCK 教学与练习平台

配合 Cambridge **Unlock 3rd Edition** 使用的英语教学与练习网站。 [打开网站](https://chaoimhinalmansour.github.io/unlockanswers.github.io/)

- 教师可使用 Book 1 至 5 的听说和读写课件备课、投屏和讲评，并查看教材原页、播放配套音视频。
- 学生可按单元做课堂练习、课后任务和听力训练，也可查看雅思 Task 1 和 Task 2 的写作批注与讲评示例。
