# UNLOCK 教师答案库

Book 2 / Book 3 · Unit 1–8 · Listening / Reading / Speaking / Writing · H1–H3。
共 192 份练习、4,800 道题、192 张图片、162 段音频。

## 使用
网页入口： https://chaoimhinalmansour.github.io/unlockanswers.github.io/
选择教材、单元、技能和练习即可查看题目，按需显示答案、展开讲评。
开放题提供参考答案；部分原资料说明较简略，页面明确标注。
音频支持播放、进度拖动、循环和 0.75× / 1× / 1.25×。
展开听力原文后可查看逐句中文、跟随播放高亮、点击句子重听；支持只读本句或从此连续播放。
共162段音频、1,796条双语字幕。未可靠对齐的词保留整句高亮，人物标签不作为朗读内容。

## 离线使用
在仓库页面选择 Code → Download ZIP，完整解压后打开 index.html。
请保留 assets 文件夹。页面无需登录或联网，不收集学生资料、完成进度。
若本地浏览器限制素材访问，可点击“关联素材”选择 assets。
